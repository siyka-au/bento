## Fields

### `http`

A list of http collectors.


Type: `array`  
Default: `[]`  

### `http[].address`

The endpoint of a collector to send metrics to.


Type: `string`  

```yml

```

### `http[].secure`

Connect to the collector over HTTPS.


Type: `bool`  
Default: `false`  

### `grpc`

A list of grpc collectors.


Type: `array`  
Default: `[]`  

### `grpc[].address`

The endpoint of a collector to send metrics to.


Type: `string`  

```yml
# Examples

address: localhost:4317
```

### `grpc[].secure`

Connect to the collector with client transport security.


Type: `bool`  
Default: `false`  

### `tags`

A map of tags to add to all metrics as resource attributes.


Type: `object`  
Default: `{}`  

### `push_interval`

The interval between pushes of accumulated metrics to the collector.


Type: `string`  
Default: `"10s"`
